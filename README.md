# python-number-analyser




#  Student Marks Analyzer

A beginner-friendly Python project that takes marks for 5 subjects and analyzes a student's academic performance. The program calculates the total marks, average marks, highest marks, lowest marks, and assigns a grade based on the average.

#  Features

* Enter marks for 5 subjects
* Store marks using a Python list
* Calculate total marks
* Calculate average marks
* Find the highest marks
* Find the lowest marks
* Automatically calculate the student's grade
* Display the complete result

#  Grading System

| Average Marks | Grade |
| ------------- | ----- |
| 90 or above   | A     |
| 75 – 89       | B     |
| 60 – 74       | C     |
| Below 60      | D     |

#  How the Program Works

1. The program creates an empty list called `marks`.
2. A `for` loop runs 5 times to take marks from the user.
3. Each mark is added to the list using `append()`.
4. The program calculates the total using `sum()`.
5. The average is calculated from the total marks.
6. `max()` and `min()` are used to find the highest and lowest marks.
7. The average is checked using `if`, `elif`, and `else`.
8. A grade from **A to D** is displayed.



# How to Run

Make sure Python is installed on your computer.

Run the program using:

```bash
python marks_analyzer.py
```

Then enter the marks when prompted.
